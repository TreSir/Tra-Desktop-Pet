# Tra Desktop Pet · 桌面上的小伙伴

一个基于 Electron 与 Canvas 2D 的桌面宠物项目。摸摸它、拖着它换个位置，或在桌面放一份小食；用赚来的羁绊币解锁表情与特效，再为同一只宠物换上一套皮肤。

日常操作集中在托盘「陪伴控制台」，商店和设置提供极光夜色、甜暖奶油、像素游乐场三种主题。

## 启动

主要面向 Windows 10 / 11。本轮开发验证使用 Node.js 24.14.0 与 npm；桌面运行时由 Electron 提供。Windows 全局投喂和隐藏快捷键使用 PowerShell 调用 Win32 API。macOS / Linux 未完成完整兼容验证。

```bash
git clone https://github.com/TreSir/Tra-Desktop-Pet.git
cd Tra-Desktop-Pet
npm ci
npm start
```

首次安装需要下载 Electron。启动后可以右键桌宠，或者点击任务栏通知区域中的托盘图标，打开控制台。关闭商店、设置或收起控制台不会退出桌宠；退出请使用控制台底部的「退出桌宠」。

目前仓库提供源码启动方式，尚未配置安装包生成或自动更新。

## 可以玩什么

### 伙伴与皮肤

现有 7 位伙伴：史莱姆、小猫、幽灵、火焰、机器人、坤坤和小树。默认外观采用翡翠绿、奶油金、紫罗兰、落日橙等不同配色。

打开控制台 →「角色衣橱」：先选伙伴，再选它的皮肤。星海蓝、极光蓝、蓝焰等旧版外观作为对应伙伴的皮肤保留，皮肤不会增加独立角色。换装会同步精灵图、光圈颜色与环境粒子色彩，并保存当前选择。

角色图片位于 `renderer/assets/`，当前素材使用 512 × 512 透明 PNG；渲染器也保留旧版背景抠图兼容逻辑。

### 互动与投喂

桌宠支持抚摸、拖动、抛掷与反弹、空中接住、缩放、眼神追踪、自然眨眼和睡眠。互动音效由 Web Audio 合成，可在设置中关闭。

在控制台 →「桌面偏好」开启「放置食物」，再按住 `Ctrl` 点击桌面，即可放下食物。也可以在商店购买小食并直接投喂。食物使用独立透明穿透窗口显示，宠物会主动靠近进食。

### 羁绊商店

摸摸、连击、拖动和空中接住可以获得羁绊币；奖励数值由 `game_config.json` 配置。

- 补给小食：消耗品，每次购买会投喂一份。
- 心情表情：永久解锁，解锁后可反复使用。
- 魔法特效：永久解锁，可分别启用或停用。

商店支持按名称或说明搜索、价格和名称排序、「只看买得起的好物」筛选，以及「我的收藏」「正在使用」分类。`Ctrl + K` 聚焦搜索框。清除筛选会重置搜索、排序和价格筛选。

### 陪伴节奏与主题

设置页提供三种一键预设：

| 节奏 | 散步 / 寻食速度 | 活力消耗 / 睡眠恢复 | 环境粒子 / 音效 |
| --- | --- | --- | --- |
| 安静陪伴 | 18 / 240 px/s | 0.2 / 2 | 关闭 / 关闭 |
| 活泼伙伴 | 48 / 480 px/s | 0.4 / 3 | 开启 / 开启 |
| 日常节奏 | 28 / 320 px/s | 0.3 / 2 | 开启 / 开启 |

预设会一次保存并立即应用。也可以继续调整滑块与开关，形成自定义节奏。「安静陪伴」控制环境粒子与音效；已购买特效的启用状态仍由商店管理。

主题可在设置或控制台切换，商店、设置和控制台会同步。系统开启减少动态效果时，这些页面会减少动画。

### 多屏与局域网

支持在多个显示器之间拖动桌宠，并在移除显示器后召回落在屏幕外的宠物。

局域网模式默认关闭。两台电脑运行应用并在控制台开启「局域网联机」后，可以自动发现伙伴，并通过控制台或抛向屏幕边缘进行传送。可以随时召回自己的宠物。

联机使用 UDP `19827` 发现、HTTP `19826` 起始端口传输；HTTP 端口被占用时会尝试其他端口。适用于可信的本地网络，不需要外部服务。连接失败时确认两端已开启联机、防火墙允许应用通信，且网络没有客户端隔离。

## 操作速查

| 操作 | 功能 |
| --- | --- |
| 左键单击桌宠 | 抚摸 |
| 按住左键拖动、松手 | 移动 / 抛掷 |
| 下落中点击桌宠 | 空中接住 |
| 滚轮 | 缩放至 0.5–2 倍 |
| Ctrl + 滚轮 | 循环切换角色 |
| 右键桌宠、点击托盘 | 打开陪伴控制台 |
| Shift + 左键点击托盘 | 打开系统原生菜单 |
| H（Windows 全局） | 隐藏 / 在鼠标附近唤回 |
| Ctrl + 左键（食物模式开启） | 放置食物 |
| Space / S / D / F / R（桌宠窗口聚焦） | 抚摸 / 睡眠切换 / 跳舞 / 投喂 / 重置缩放 |
| Ctrl + K（商店内） | 聚焦搜索 |
| Esc（控制台、商店、设置内） | 收起 / 关闭当前面板 |

控制台栏目支持方向键与 Home / End 切换。开启智能点击穿透后，桌宠之外的窗口区域可正常操作。

## 配置与存档

运行数据保存在项目根目录 `.userdata/`，已被 Git 忽略：

| 文件 | 内容 |
| --- | --- |
| `settings.json` | 速度、活力、粒子、声音和主题偏好 |
| `character.json` | 当前角色与皮肤 |
| `coins.json` | 羁绊币余额 |
| `shop_unlocks.json` | 已解锁商品与启用特效 |

退出应用后可备份这些文件。移动项目时同时保留 `.userdata/` 可保留进度。该目录也包含 Electron 缓存与运行日志，不要提交到仓库。

编辑根目录 `game_config.json` 后重启，可调整互动奖励、角色与皮肤配置、商品目录。新增图片路径相对于 `renderer/`，例如 `assets/my-pet.png`。透明 PNG 推荐使用方形画布，并在 `characters` 对应项中设置 `transparent: true`。

## 开发

```bash
npm start       # 启动 Electron 应用
npm run check   # 检查主进程、预加载、渲染器和脚本的 JavaScript 语法
```

语法检查不代替实际交互验证。修改窗口或 IPC 后，建议手动验证打开 / 关闭面板、保存设置、购买与特效切换；修改角色后验证默认外观和皮肤切换；修改物理或联机后验证多屏边界与两端传送。

```text
desktop-pet/
├── main.js                 # 窗口、IPC、物理、设置与全局快捷键
├── tray-panel.js           # 自定义托盘控制台与原生菜单动作桥接
├── lan.js                  # 局域网发现与传输
├── game_config.json        # 角色、皮肤、商店与奖励配置
├── *_preload.js            # 面板的隔离通信接口
├── preload.js              # 桌宠通信接口
├── renderer/
│   ├── app.js              # 行为、状态、渲染与交互
│   ├── characters.js       # 精灵图、皮肤与抠图兼容
│   ├── effects.js          # 粒子与绘制效果
│   ├── sound.js            # 程序化互动音效
│   ├── ui.css / ui-common.js # 面板共享样式与主题
│   ├── tray.*              # 控制台
│   ├── shop.html / shop.js # 商店
│   ├── settings.html / settings.js # 设置
│   ├── food_window.html / food.js # 食物图层
│   └── assets/             # 角色透明图片
├── scripts/check.cjs       # 语法检查入口
└── .userdata/              # 本地存档与缓存（不跟踪）
```

项目当前仅依赖 Electron 作为开发依赖；Canvas、Web Audio 与 Node.js 内置模块承担主要功能。面板使用 `contextIsolation` 与预加载接口，关闭 Node.js 集成。
