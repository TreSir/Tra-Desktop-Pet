# Tra-Desktop-Pet · 数字共生体桌宠

> 一只住在你桌面上的暗色粘液生物 —— 会呼吸、会眨眼、会被你扔出去弹跳，还会顺着屏幕边缘溜到同事的电脑上。

基于 Electron + Canvas 构建的零依赖桌宠应用，自带 AI 生成精灵图、绿幕抠图、物理引擎、表情系统与局域网联机玩法。

---

## ✨ 特性一览

### 🐾 多角色系统
内置 7 个角色，每个都通过 AI 生成精灵图 + 实时绿幕抠图渲染：

| 角色 | 风格 | 备注 |
| --- | --- | --- |
| 🟦 史莱姆 | Q 版果冻 | 默认角色 |
| 🐱 小猫 | Q 版萌宠 | |
| 👻 幽灵 | 半透明灵异 | |
| 🔥 火焰 | 动态炽热 | |
| 🤖 机器人 | 机械质感 | |
| 🐔 坤坤 | 人形角色 | 仅你懂 |
| 🌳 小树 | 植物系 | 严格绿幕模式（防树叶误扣） |

切换角色时会播放缩小→爆星→放大的形变动画。

### 😊 表情与状态系统
- **12 种情绪**：高兴 / 愤怒 / 悲伤 / 鄙夷 / 坏笑 / 震惊 / 害怕 / 放松 / 得意 / 困倦 / 晕眩 / 心动
- **6 种任务状态**：待机 / 工作中 / 等待确认 / 任务成功 / 任务失败 / 思考中
- 心情值自动驱动表情切换（love → happy → proud → relaxed → disdain → sad → angry）
- 支持脸红、心形粒子、汗滴、星尘等情感反馈

### 🎮 物理与交互
- **抛掷物理引擎**：拖起桌宠扔出去，带重力、弹跳、摩擦、墙壁反弹
- **眼球追踪**：瞳孔会跟随鼠标移动
- **滚轮缩放** / **长按挣扎** / **边缘窥探**
- **自动行走**：在屏幕底部随机漫步
- **点击穿透**：一键让桌宠变成纯背景装饰，不影响工作
- **睡眠模式**：长时间不动会自动入睡，呼吸变缓

### 🍎 食物系统
开启「放置食物模式」后，**Ctrl + 左键** 在桌面任意位置放置食物（🍎🍖🍰🍬🍪🥕🐟🧀），桌宠会自己走过去吃掉。

通过 PowerShell 全局钩子监听 Ctrl+左键，再用一个全屏透明 click-through 窗口渲染食物图标，全程不影响桌面操作。

### 🌐 局域网联机
零依赖实现的局域网多人玩法：
- **UDP 广播自动发现** 同网段内的其他桌宠用户
- **HTTP 传输**桌宠状态（表情、心情、角色）
- 把桌宠**抛向屏幕边缘**，它会飞到对方的屏幕上继续活动
- 也可在托盘菜单中「扔给…」指定 peer

> 端口：HTTP `19826` / UDP 发现 `19827`，无需任何外部依赖。

### 🖼 系统托盘
- 切换角色 / 表情 / 任务状态
- 喂食 / 跳舞 / 睡眠切换 / 重置缩放
- 点击穿透 / 自动行走 / 食物模式开关
- 联机模式开关与 peer 列表
- 角色配置持久化（重启后保留上次选择）

## 🚀 快速开始

### 环境要求
- Node.js ≥ 16
- Windows（食物模式与全局鼠标钩子依赖 PowerShell，其他平台可运行但功能受限）

### 安装与运行

```bash
git clone https://github.com/<your-username>/Tra-Desktop-Pet.git
cd Tra-Desktop-Pet
npm install
npm start
```

启动后，桌宠会出现在屏幕底部中央，右下角托盘图标可呼出全部菜单。

## 🛠 技术亮点

### 绿幕抠图（`renderer/characters.js`）
- 采样四角像素中值作为背景色，自适应不同绿幕
- **严格绿幕模式**：检测到纯绿幕背景时启用 R/B 容差判断，避免把树叶绿色误扣
- 窄过渡区抗锯齿（`hardCutoff` → `hardKeep`）让边缘锐利不发糊
- 溢色修正：把边缘绿色通道拉向 R/B 最大值，去除绿边
- 邻居像素清理：孤立半透明像素直接清零，防止 shadowBlur 放大成方框
- 自动去除右下角水印

### 物理引擎（`main.js`）
- 16ms tick（约 60 FPS）的抛掷物理：重力、地面弹跳、摩擦衰减
- 静止判定自动停止定时器，节省 CPU
- 联机模式下检测边缘飞出，触发桌宠转移

### 零依赖联机（`lan.js`）
- 仅用 Node.js 内置 `dgram` + `http` + `os` + `crypto`
- 定向子网广播（比 `255.255.255.255` 更可靠）
- Peer 超时自动清理（10 秒未刷新心跳）

## ⚠️ 已知限制

- 角色素材为 AI 生成，可能存在抠图瑕疵
- 联机模式目前不支持跨网段
