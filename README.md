# Tra-Desktop-Pet · 数字共生体桌宠

> 一只住在你桌面上的智能桌面共生体 —— 会呼吸、会眨眼、会被你扔出去弹跳，还会顺着屏幕边缘溜到局域网同事的电脑上。

基于 **Electron 33 + 原生 Canvas 2D** 构建的轻量级、**零运行时外部依赖**桌宠应用。集成了多角色皮肤换装、Win32 全局快捷投喂、抛掷物理引擎、局域网跨屏互动、羁绊经济与全新毛玻璃控制台面板。

---

## ✨ 核心特性

### 🐾 角色与衣橱系统 (Characters & Skins)
- **7 种初始角色**：史莱姆（🟦）、小猫（🐱）、幽灵（👻）、火焰（🔥）、机器人（🤖）、坤坤（🐔）、小树（🌳）。
- **个性化皮肤变体**：支持角色深度换肤（如星海蓝、蓝焰、极光蓝、翡翠绿、奶油金等）。
- **双轨素材引擎**：
  - **原生透明通道**：高清透明 PNG 精灵图，边缘柔和无锯齿；
  - **智能绿幕抠图兼容**：对旧版带背景素材支持四角中值背景采样、纯绿幕严格容差判定、溢色校正与边缘孤立像素清理，彻底解决绿边与矩形黑框问题；
- 换装形变动画：切换角色时播放细腻的「缩小 → 爆星 → 放大」弹性转场。

### 🎮 物理仿真与深度交互 (Physics & Interaction)
- **60 FPS 抛掷物理**：长按拖起桌宠用力甩出，体验重力加速度、地面反弹与空气摩擦阻尼。
- **空中受身拦截**：桌宠自由落体期间，可以在半空中用鼠标「接住」它，触发特殊奖励与欢快反馈。
- **眼球与视线追踪**：基于 80ms 低频光标轮询，瞳孔与角色面部实时跟随鼠标微动。
- **自由交互手势**：滚轮无级缩放大小（0.5x ~ 2.0x）、长按挣扎、边缘窥探、连击旋转等。

### 🍎 桌面级食物投喂 (Food & Global Hook)
- **桌面随处投喂**：开启食物模式后，通过 **`Ctrl + 鼠标左键`** 在屏幕任意软件上方投喂美食（🍎、🍖、🍰、🍬、🍪、🥕、🐟、🧀）。
- **极轻量全局钩子**：主进程通过后台轻量 PowerShell 进程调用 Win32 API（`GetAsyncKeyState` + `GetCursorPos`）边沿触发，无外部原生依赖编译。
- **全屏穿透图层**：食物通过全屏透明、点击完全穿透（Click-Through）的独立窗口渲染，不干扰任何日常办公操作。
- **智能寻路进食**：桌宠会感知到食物坐标，自动采用非线性缓动自主走过去吃掉并获得体力与心情奖励。

### 🌐 零依赖局域网跨屏互动 (LAN Multiplayer)
- **纯原生技术实现**：仅依靠 Node.js 内置的 `dgram`、`http`、`os` 和 `crypto` 模块，无需任何外部服务器或第三方库。
- **局域网自动发现**：通过 UDP 广播（端口 19827）秒级发现同网段在线的小伙伴。
- **跨屏幕飞跃**：将桌宠大力抛向屏幕边缘，桌宠将化作流光飞出当前电脑，穿透网络出现在同事的桌面上继续散步！也可以通过控制台一键定向传送。

### 🪙 羁绊经济与魔法商店 (Bonds & Shop)
- **互动产币机制**：每一次摸摸、连击、空中接住宠物都会掉落「羁绊币」并伴随浮空飘字动画。
- **商品分类与解锁**：
  - **补给小食**：苹果、糖果、肉块、鱼肉、蛋糕等，即时恢复心情与能量；
  - **限定表情**：解锁得意（😏）、晕眩（💫）、邪笑（😬）、爱心眼（♥）等特殊表情；
  - **魔法特效**：心形环绕（💗）、星尘粒子（✨）、闪电移动拖尾（⚡）、全屏彩虹光环（🌈）。

### 🎨 现代毛玻璃控制台与双轨 UI (Companion Console)
- **现代弹出控制台**：鼠标右键或左键单击任务栏托盘，即可呼出圆角毛玻璃微拟物风格的控制台面板（日常陪伴 / 角色衣橱 / 桌面偏好）。
- **原生平滑降级**：按住 `Shift` 单击或在特殊异常时，无缝回退至系统原生右键菜单。
- **三套全局主题**：
  - 🌌 **极光 · 夜色 (Aurora)**：暗黑背景 + 薄荷青冷光；
  - 🥞 **甜暖 · 奶油 (Sweet)**：暖色纸感 + 焦糖拿铁暖光；
  - 👾 **像素 · 游乐场 (Pixel)**：复古暗紫 + 荧光青柠。

### 🎵 零依赖 Web Audio 萌系微音效 (Procedural Audio)
- **纯代码数学合成**：无需加载任何外部 mp3/wav 音频文件，纯依靠浏览器原生 `AudioContext` 实时振荡生成；
- **全交互音效覆盖**：
  - 抚摸桌宠（温润小可爱音）、连击（随 Combo 阶梯上升音阶）；
  - 获得金币（经典清脆双音跳变）、进食食物（爽快咀嚼声）；
  - 空中受身接住（四音上行大琶音鼓励音）、落地砸地（低沉噗通声）；
  - 入睡打鼾与唤醒音效；
- **静音偏好管理**：在设置面板中可随时开启或关闭音效。

### 🖥 多显示器自适应与跨屏无缝漫步 (Multi-Monitor Support)
- **多屏自由拖拽**：打破单屏限制，支持在多个不同分辨率、不同 DPI 的外接屏幕之间自由拖动桌宠；
- **动态地面与物理检测**：重力与抛掷碰撞实时计算当前所在屏幕的可用工作区与地面高度；
- **拔出屏幕自动召回**：智能监听 `display-removed`，拔掉扩展坞或外接屏时，若桌宠处于失联区域，会自动优雅召回主屏幕底部中央。

### 💤 生物节律与极致能耗优化 (Optimization)
- **昼夜节律与睡眠系统**：30 秒无交互自动打瞌睡，夜间更容易入眠；
- **高能效资产瘦身**：所有透明高清精灵图经高品质优化重构为 512×512，素材体积与 GPU 显存占用骤降 80% 以上；
- **自适应动态调频**：活跃状态 60 FPS 流畅物理 / 睡眠状态 ~20 FPS / 隐藏状态 ~10 FPS；
- **粒子对象池**：采用 `freeStack` 栈式对象池管理粒子，消除 GC 卡顿；
- **安全与防数据损坏**：用户设置与金币采用原子临时写入机制，退出时干净销毁 PowerShell 进程树，杜绝后台僵尸进程。

## 🎯 操作与快捷键指南

### 鼠标操作
| 操作 | 对应反馈 |
| :--- | :--- |
| **鼠标左键单击** | 摸摸桌宠（增加好感度、产出羁绊币） |
| **按住左键拖动** | 抓起桌宠蓄力，松手即可进行抛掷 |
| **自由落体中点击** | 空中受身拦截（心情大增，获得大量金币） |
| **滚轮滑动** | 自由无级缩放桌宠大小（0.5x ~ 2.0x） |

| **托盘图标单击** | 唤醒/收起控制台面板（Shift+单击呼出原生菜单） |

## 🚀 快速上手

### 环境要求
- **Node.js** ≥ 16.0.0
- **操作系统**：Windows 10 / 11（食物放置与全局快捷键依赖轻量 PowerShell，macOS / Linux 基础桌宠功能可运行但全局钩子受限）

### 安装与启动

1. **克隆项目到本地**：
   ```bash
   git clone https://github.com/<your-username>/Tra-Desktop-Pet.git
   cd Tra-Desktop-Pet
   ```

2. **安装开发依赖**（仅 Electron，无多余依赖）：
   ```bash
   npm install
   ```

3. **启动桌宠**：
   ```bash
   npm start
   ```

启动后，桌宠会自动降落在屏幕底部中央；你可以直接用鼠标拖动玩耍，或者右键桌宠开启专属功能！

## ⚙️ 个性化配置

你可以直接编辑根目录下的 [`game_config.json`](game_config.json) 自定义游戏数值与角色属性（修改后重启生效）：
- **金币掉落率**：修改 `coins.rewards` 调整抚摸、连击与接住桌宠的金币数；
- **扩展角色/皮肤**：在 `characters` 中挂载自定义精灵图资源与发光色彩；
- **商店商品**：在 `shop` 中增加或修改食物补给、解锁表情及增益效果。
